Todo programa de Arduino tiene 2 partes

setup( ) y loop( )

🎒 setup( )

Como preparar la mochila en la mañana: se hace una sola vez, al encender.

🔁 loop( )

Como tu rutina del día: se repite una y otra vez, sin parar, para siempre.

✓→mi_primer_programa.ino
void setup() {
  // esto pasa 1 sola vez
}

void loop() {
  // esto se repite ∞ veces
}

Tu primer programa de verdad

Blink: el saludo de Arduino 👋

✓→blink.ino
void setup() {
  pinMode(13, OUTPUT);   // el pin 13 va a dar órdenes
}

void loop() {
  digitalWrite(13, HIGH); // ¡enciende!
  delay(500);              // espera medio segundo
  digitalWrite(13, LOW);  // apaga
  delay(500);              // espera otra vez
}

HIGH = encendido · LOW = apagado · delay = espera (en milésimas de segundo)

Reglas de electricista profesional

Seguridad primero ⚡

🔌 Regla 1

Para cambiar cables, primero desconecta el USB. Siempre.

👀 Regla 2

Antes de conectar, tu compañero revisa tu circuito (y tú el suyo).

🖐️ Regla 3

¿Algo huele raro o se calienta? Desconecta y avisa.

Arduino usa 5 voltios: no puede hacerte daño, pero un cable mal puesto sí puede dañar la placa.
